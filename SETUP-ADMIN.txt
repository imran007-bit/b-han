B HAN — SECURE ADMIN SETUP (one-time, 5 minutes)
==================================================

The admin panel now uses Firebase login (much more secure than the old password).
Do these steps AFTER pushing the new files to GitHub:

STEP 1 — Make sure you have an account in the app
  - Open b-han.vercel.app and register/login with YOUR email (you already did this).

STEP 2 — Find your UID
  - Firebase Console → Authentication → Users tab
  - Find your email → copy the "User UID" (long string like: aB3xY9...)

STEP 3 — Create the admins allowlist
  - Firebase Console → Firestore Database → "Start collection"
  - Collection ID:  admins
  - Document ID:    (paste YOUR UID here)
  - Add field:      role  =  owner   (string)
  - Save

STEP 4 — Deploy the new rules
  - Firestore Database → Rules tab
  - Delete old rules, paste the full contents of firestore.rules from this zip
  - Publish

STEP 5 — Login to admin
  - Go to b-han.vercel.app/control-bhan-2025.html
  - Sign in with YOUR EMAIL + PASSWORD (same as the app)
  - Old password (bhan2025admin) no longer used when online.

WHAT THIS PROTECTS:
  - Before: anyone could read ALL orders + customer names/phones/addresses
  - Now: customers see only their own data; only YOU (admins list) can
    read everything, edit products, update tracking, change settings.
  - Order tracking by exact order ID still works for everyone (IDs are random).

EVERYTHING ELSE YOU CONTROL FROM ADMIN PANEL (no code needed):
  products, prices, photos, coupons, orders, tracking, customers,
  hero text, announcement bar, WhatsApp numbers, bKash/Nagad numbers,
  shipping rates, free-shipping threshold, categories, colors.
